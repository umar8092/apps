    Questions

    Will the till scanner read my phone?

    Most shop scanners today read phone screens. Turn the screen brightness up, hold the phone flat and still, about 10 to 20 cm from the scanner. If it still does not read, the cashier can type the large number shown under the barcode.

    Which barcode type is my card?

    Leave Barcode type on Work it out for me. A 13-digit number becomes EAN-13 (most supermarkets), 12 digits UPC-A (US and Canada), 8 digits EAN-8, and anything else Code 128. A square code on your card is a QR code. Compare the bars in How it will look at the till with your plastic card; thin and thick bars in a similar pattern means it is right.

    The app says the last digit does not match

    EAN and UPC numbers end with a check digit worked out from the others, so a typing mistake shows up straight away. Check the number on your card. If it really is printed like that, the card uses a different barcode and the app shows it as Code 128.

    Two people in the family have the same shop's card

    Add each one and type the name under Whose card (for example Mum or Ali). The name shows on the card and on the barcode screen.

    Does it work with no signal, and is it private?

    Yes. After the first visit the app works offline, so it opens in a shop basement with no signal. Cards are saved on this device only, there is no account, and your data is never sent anywhere. Use Save a backup file before you change phones.
