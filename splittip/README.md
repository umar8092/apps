# SplitTip

Free bill splitter that shows who owes who. Enter what each person paid and see who pays whom, then open your mail app with the summary filled in. Also splits a check evenly, or by what each person ordered with tax and tip shared fairly. Works offline, installable, no sign-up, no ads.

**Live:** https://umar8092.github.io/apps/splittip/

- Plain HTML, CSS and JavaScript, no build step. Open `index.html`.
- All money is handled in whole cents, so shares always add up exactly.
- Checks: `node tests.js`, or open `test.html` in a browser.
