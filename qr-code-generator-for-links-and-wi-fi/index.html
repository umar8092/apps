QR Code Generator for Links and Wi-Fi

Make a QR code for a link, your Wi-Fi, a contact, a phone number or a message. It never expires, and your data is never sent anywhere.

What should the code do?

Paste the whole link from your browser. It can be a menu, a review page, a form, a video or a shop.

Type the name and password exactly, with the same capital letters. They are on the sticker on the router.

Scanning it offers to save you in the phone's contacts. Fill in only what you want to share.

Scanning it opens the phone's dialler with this number ready to call.

Scanning it opens the messages app with the number and message filled in. The person still taps send.

Scanning it opens the mail app with the email written. The person still taps send.

Scanning it shows this text on the phone. Works without internet.

    Colours and size

    Higher error correction still scans when part of the code is damaged, but makes it a little denser.

    SVG files have no fixed size and stay sharp at any size, so use SVG for big printing.

      Questions
      
        
      Will my QR code stop working?
      No. What you type is written straight into the code. There is no short link through this website and no account to run out, so it keeps working for as long as your link, Wi-Fi password or number stays the same. If you change your Wi-Fi password, make a new code.
      
        
      How do guests join my Wi-Fi with it?
      They open the camera on an iPhone or Android phone, point it at the code and tap the Wi-Fi notice that appears. Type the network name and password exactly, with the same capitals and spaces, or the phone cannot join.
      
        
      How big should I print it?
      At least the width the app shows under the code, never under 2 cm (0.8 in). For a poster seen from a distance, make it about a tenth of that distance wide: 30 cm (1 ft) for 3 m (10 ft). Use Download SVG for large printing.
      
        
      Can I use my own colours?
      Yes, as long as the dots stay dark and the background light. Many phone cameras cannot read light dots on a dark background, so the app warns you.
      
        
      Is it private?
      Yes. There is no account. The code is made on your device, your data is never sent anywhere, and the app works offline once it has loaded.
